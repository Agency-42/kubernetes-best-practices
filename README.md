# Kubernetes Best Practices

A practical collection of best practices, checklists, and example configurations for running Kubernetes in production.

Maintained by Agency 42, a Sweden-based IT consulting company specializing in DevOps, Kubernetes, cloud infrastructure, and cybersecurity compliance.

## What this repository covers

- Production readiness
- Cluster hardening
- Networking and ingress
- Monitoring and logging
- Backup and disaster recovery
- Workload security
- Resource management
- Operational checklists

## Who this is for

This repository is intended for platform engineers, DevOps teams, cloud architects, and organizations running Kubernetes in development, staging, or production environments.

## Repository structure

- `docs/` contains practical guidance and recommendations
- `examples/` contains example YAML manifests
- `checklists/` contains operational and security checklists
